# Checkers: what each one checks and how it was tested

Each checker is frozen: sha256 values are in the `CHECKER` lines of `reverify_light.log` and `reverify_heavy.log`. All of them parse the
instance with `verify.py`'s parser. `verify.py` is the schedule checker, validated on all 454 published RG300 schedules and 497 J120
schedules before any solver code existed.

Used unchanged from the next session on.
